# Invitación cumple de Juana

Página de invitación: cartel, música (Night Changes – One Direction) con scroll automático, cuenta regresiva al 25 de octubre 16:30 hs y botón para confirmar asistencia por WhatsApp.

Para editar el número de WhatsApp, el lugar o la velocidad del scroll, cambiá el bloque `CONFIG` al principio del `<script>` en `index.html`.
